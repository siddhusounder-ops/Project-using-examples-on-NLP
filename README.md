# Natural Language Processing Basics

A collection of practical NLP examples built with **NLTK**, **Gensim**, and **scikit-learn**, walking through the core text-processing pipeline step by step.

What's covered

- **Stemming** — Porter & Snowball stemmers
- **Lemmatization** — WordNet lemmatizer with POS-aware examples
- **Tokenization** — sentence and word tokenization
- **Stopword removal** — filtering common words with NLTK's stopword corpus
- **POS tagging** — part-of-speech tagging with the averaged perceptron tagger
- **Chunking** — regex-based noun phrase (NP) chunking
- **Named Entity Recognition (NER)** — extracting entities from tagged text
- **Word2Vec** — pre-trained `word2vec-google-news-300` embeddings, sentence vectorization, and cosine similarity between sentences

 Requirements
 
- Python 3.x
- `nltk`, `gensim`, `numpy`, `scikit-learn`

## Usage
Open `NLP.ipynb` in Jupyter/Colab and run the cells sequentially — required NLTK corpora are downloaded inline as needed.
